# 美化管理器（TT 试用版）0.1.0

## 安装
1. 解压本压缩包。
2. 将整个 `theme-manager-tt-test` 文件夹放入 TT 的第三方扩展目录（或 TT 扩展管理器支持的本地扩展目录）。
3. 在 TT 扩展管理界面启用扩展；若 TT 不自动发现，请按 TT 的本地扩展加载方式重新扫描/刷新。
4. 刷新 TT 页面，右下角会出现「✿」悬浮按钮。

## 本版用于验证
- 是否能在 TT 2.4 正常加载第三方扩展。
- 是否能通过 `/api/settings/get` 读取主题列表。
- 点击「应用美化」是否能调用 TT 原生 `#themes` 控件切换主题。
- 管理器浅色/深色、强调色、卡片列数、悬浮球大小独立保存，不跟随酒馆外观。
- 分类、作者、备注、标签保存在浏览器 IndexedDB，不写入聊天数据。

## 已知未包含
这是先验证 TT 2.4 接口的试用版，不是完整功能版：
- 尚未迁移原版 90 个美化的截图/标注数据。
- 尚未加入背景绑定、日夜配对、系列、批量导入导出和备份恢复。
- 暂未实现原版所有 UI 自定义项，也不是原作者完整 UI 的逐项移植。
- 本版不包含任何头像管理功能。

## 测试后请反馈
1. TT 是否识别并加载扩展。
2. 悬浮按钮是否出现。
3. 能否读取主题列表。
4. 点击主题后是否真的切换成功；若失败，请把浏览器控制台中 `[TM-TT试用版]` 的报错发回。
